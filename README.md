# 🪔 ভূরভুষিকালী সার্বজনীন শ্রীশ্রী দূর্গা মন্দির — প্রণামি সংগ্রহ

সম্পূর্ণ বাংলা, মোবাইল + ডেস্কটপ রেসপন্সিভ, Supabase ডাটাবেস।

## ⚠️ প্রথমে করুন: নতুন schema.sql চালান

ইউজার ম্যানেজমেন্ট + তারিখ ফিচার যোগ হয়েছে। Supabase Dashboard → **SQL Editor** →
`supabase/schema.sql`-এর **পুরো SQL** paste → **Run**। পুরনো ডেটা মুছবে না, নতুন
টেবিল/কলাম/ফাংশন যোগ হবে।

## পেজসমূহ (URL)

| পেজ | URL | বিবরণ |
|-----|-----|-------|
| 📝 প্রণামি ফরম (সবার জন্য) | `/` | **এই লিংকটাই সবাইকে পাঠান** — শুধু ফরম দেখাবে |
| 🤝 প্রণামি সংগ্রহ (সুরক্ষিত) | `/collect` | সংগ্রাহকদের ফরম (নাম, ঠিকানা, টাকা, **তারিখ** — ডিফল্ট আজ) |
| 🔐 অ্যাডমিন (সুরক্ষিত) | `/admin` | সব তথ্য + ইউজার ম্যানেজমেন্ট |

## ইউজার সিস্টেম

- **প্রধান অ্যাডমিন** (fixed): `.env`-এর `VITE_ADMIN_USERNAME/PASSWORD` — এটাই সবার শীর্ষে, মুছা যায় না।
- **সাব-অ্যাডমিন**: শুধু প্রধান অ্যাডমিন তৈরি/মুছতে পারেন। সব কিছুর অ্যাক্সেস আছে (ডেটা দেখা, যাচাই, CSV, সংগ্রাহক তৈরি/মুছা) — শুধু সাব-অ্যাডমিন তৈরি/মুছা পারেন না।
- **সংগ্রাহক**: প্রধান বা সাব-অ্যাডমিন তৈরি/মুছতে পারেন (নাম + ঠিকানা + ইউজার আইডি + পাসওয়ার্ড)। লগইন করে মাঠের প্রণামি জমা দেন — অ্যাডমিন প্যানেলে কে সংগ্রহ করল সেটা দেখা যায়।

প্রতিটি তৈরি করা ইউজারের নাম, ঠিকানা, ইউজার আইডি ও পাসওয়ার্ড লাগে। পাসওয়ার্ড
সার্ভারে SHA-256 হ্যাশ হয়ে সংরক্ষিত থাকে — কেউ পড়তে পারে না।

## সেটআপ

```bash
npm install
cp .env.example .env   # আসল value বসান (Supabase URL/KEY, প্রধান অ্যাডমিন পাসওয়ার্ড)
npm run dev            # http://localhost:5173
```

### দাম ও পেমেন্ট নম্বর বদলান
`src/config.ts` → `PRICES` (গীতা/গাছ/কাপড়) ও `PAYMENT_NUMBERS`
(বিকাশ/রকেট/নগদ রিসিভার: +880 1956-508898)।

### ডেপ্লয় (Vercel)
`npm run build` → Vercel-এ import → একই env variable বসান → `/` লিংক সবাইকে পাঠান।

## সমস্যা হলে
- **"টেবিল/ফাংশন পাওয়া যায়নি"** → `supabase/schema.sql` আবার চালান।
- **"Supabase কী ভুল"** → `.env`-এর URL/KEY যাচাই করুন।
- **লগইন হচ্ছে না (UI-তে তৈরি নয়)** → SQL Editor-এ সরাসরি ঢোকানো ইউজারের হ্যাশ ফরম্যাট আলাদা হতে পারে — অ্যাডমিন প্যানেলের **ইউজার ম্যানেজমেন্ট** থেকে আবার তৈরি করুন।
- **সাদা/blank পেজ** → `.env` আছে কিনা দেখুন; browser console-এর এরর দেখুন।

## নিরাপত্তা নোট
- অ্যাপটি Supabase **anon key** ভিত্তিক (ক্লায়েন্ট-অনলি সাইটের স্বাভাবিক সীমা)।
- `app_users` টেবিলে সরাসরি কোনো অ্যাক্সেস নেই — লগইন/তৈরি/মুছা সব সার্ভার-সাইড RPC দিয়ে।
- আরও শক্ত সুরক্ষা চাইলে ভবিষ্যতে Supabase Auth-এ মাইগ্রেট করা যাবে।
